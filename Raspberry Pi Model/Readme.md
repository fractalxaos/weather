<h4>DIY Weather Station</h4>
<p>
Building a do-it-yourself (DIY) weather station is an exciting way to learn about the "Internet of Things".  Building the weather station will give you an excellent introduction to a variety of technologies.  You will learn about programming Arduino micro-controllers, assembling electronic components, and using solar energy to power your project.  You will learn about Linux server software systems and architecture, scripting for Internet applications, and displaying information in a web page.
</p>
